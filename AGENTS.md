# Repository Investigation Boundaries

- Do not read, list, search, stat, hash, or otherwise inspect files or paths outside this repository unless Tomas explicitly authorizes the exact external scope first.
- Do not query, enumerate, attach to, trace, signal, or otherwise inspect live processes or threads unless Tomas explicitly authorizes that live-process inspection first.
- This prohibition includes `/proc`, system or user journals, service state, mounted-media contents, installed binaries, desktop launchers, and compositor or window-manager state.
- A request to investigate or modify this repository does not imply permission to inspect the surrounding host system.
